# 3 en Raya — Neon Edition

Tres en raya con estética neon, animaciones y modo contra CPU.

## Cómo jugar

Abre `index.html` en tu navegador (doble clic o arrastra al navegador).

También puedes servirlo localmente:

```bash
npx serve .
```

## Características

- Modo 2 jugadores, vs CPU y **torneo** (al mejor de 3, 5 o 7)
- CPU con 3 dificultades: Fácil, Media y Difícil
- **Efectos de sonido** sintetizados (activar/desactivar con 🔊)
- Marcador persistente en localStorage
- Animaciones de fichas, línea de victoria y partículas
- Diseño responsive
