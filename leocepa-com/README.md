# LeoCepa.com

Mi página web personal con todos mis juegos.

## Cómo verla en el ordenador

Abre `index.html` con doble clic (mejor si abres la carpeta con un servidor local).

## Cuando creo un juego nuevo

1. Creo una carpeta nueva en `Projects/` con un `index.html`.
2. Añado el juego en `project-meta.json` (título, emoji y descripción).
3. Ejecuto en la terminal:

```bash
node leocepa-com/scan-projects.mjs
```

¡Y el juego aparece solo en la web!

## LeoCepa.com en internet

La web está en GitHub Pages. Para usar tu dominio `leocepa.com`, configura en GitHub los DNS de tu dominio apuntando a GitHub Pages.
