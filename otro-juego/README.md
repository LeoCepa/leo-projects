# Zorro — Supervivencia

Juego pixel art sobre un zorro que debe sobrevivir en el bosque.

## Escena de apertura

Dos zorros juegan al atardecer. Un cazador aparece y dispara; uno muere y el otro escapa.

## Cómo jugar la demo

Abre `index.html` en el navegador (doble clic o con un servidor local).

```bash
npx serve .
```

Pulsa **ESPACIO** al final de la escena para ver el mensaje de continuación.
